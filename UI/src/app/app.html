Technical Information

Research tool: random scores do not establish physical energy or clinical properties. Webcam-derived randomness is experimental; entropy is not verified.

Startup discards 15 frames and waits for frame differences. Sparse pixel intensity comparisons produce candidate bits. Directional scene/exposure changes are skipped; rejected sample windows do not erase stored hotbits.

Von Neumann pairs (01 → 0, 10 → 1; equal pairs discarded) reduce bias only under independence assumptions. Motion, exposure changes and camera artifacts can produce correlations. Basic bias and repetition checks do not prove unpredictability.

Each rate receives ten inclusive 0–10 draws, summed as its energetic score. The top 20 receive three inclusive 0–1000 draws; GV is their maximum, favoring higher values. If base GV exceeds 950, add 0–100 draws and repeat while the latest added draw exceeds 95. Final order: GV, energetic score, original list order.

Duplicate names remain independent rows in original order. Every draw consumes fresh conditioned hotbits using rejection sampling. Failed attempts retire consumed material and return no partial results. There is no PRNG fallback. Raw bits and integers are never displayed.

Camera access requires HTTPS or localhost. If access is denied, enable camera permission in browser settings and press Start Collection again. All camera processing and imported data remain local; no images or files are uploaded.
